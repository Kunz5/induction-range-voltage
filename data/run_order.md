Committed before any main-run data. Generated by `analysis/gen_order.py`,
seed **20261014**. Re-running the script must reproduce this list exactly.

**Reproduction checked**, byte-identical, on CPython 3.10.12 and 3.13.16. The
Mersenne Twister sequence is stable across those versions for `shuffle` and
`sample`; if a future run disagrees, record the Python version rather than
editing this file.

Constraints, all verified against the generated list: 8 distances × 5 repeats =
40 primary trials; each distance exactly 5 times; never the same distance twice
in a row, including across block boundaries; 4 blocks of 10, each containing
every distance at least once. Each block is bracketed by a no-target `V*` sweep
at start and end — fixed, not randomised, because they measure drift. Within
every trial, voltage steps **down** from 5.0 V in 0.01 V steps; only the order
of distances is randomised.
